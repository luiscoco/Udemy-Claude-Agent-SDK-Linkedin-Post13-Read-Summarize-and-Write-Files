# Greeting Demo

A small Python command-line application for greeting a user.

## Features

- Accepts a name as a command-line argument.
- Prints a friendly greeting containing that name.
- Uses only the Python standard library.

## Run

```console
python greet.py Ada
```

Expected output:

```text
Hello, Ada! Welcome to the demo project.
```

If no name is supplied, the application greets `World`.

## Project scope

This is a local teaching demo. It has no web API, database, deployment setup,
or external service integration.
