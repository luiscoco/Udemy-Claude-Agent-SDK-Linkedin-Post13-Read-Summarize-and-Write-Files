# Project Summary

Greeting Demo is a small Python command-line application that prints a friendly
greeting. It accepts a name as an optional command-line argument and greets
`World` when no name is supplied. It uses only the Python standard library.

Run `python greet.py Ada` from the sample project folder to print
`Hello, Ada! Welcome to the demo project.` This is a local teaching demo with
no web API, database, deployment setup, or external service integration.
